Diagnosing in-app imports without driving the GUI:

- `%TEMP%\vishwakarma_dxf_import_stderr.log` is rewritten (CREATE_ALWAYS) on **every** worker spawn;
  `%TEMP%\vishwakarma_dxf_import_result.log` gets "OK: ..."/"FAILED: ..." at the end of
  RunQueuedDxfImport. Timestamps prove whether an import actually ran. Early spawn failures (missing
  deployed main.py / worker exe) write NO marker. STD equivalents:
  `vishwakarma_std_import_{result,stderr}.log`.
- The worker executes the **deployed** scripts at `build\<cfg>\extensions\<name>\main.py`, not the
  repo copies. Release deploy can be stale vs Debug.
- Standalone drive: spawn `VishwakarmaExtension.exe main.py` (cwd = deployed ext dir), write
  4-byte-LE-length-prefixed `HostToWorker` to stdin, parse `WorkerToHost` frames from stdout (oneof
  field: 2=log 3=result 4=page2d 5=asset2d). System python has protobuf and can import the deployed
  `ExtensionIPC_pb2`; hand-encoded protobuf also works fine.
- Full-app e2e: env `VISHWAKARMA_AUTO_IMPORT_DXF` / `VISHWAKARMA_AUTO_IMPORT_STD=<file>` auto-imports
  at startup. The GUI's std::cout **is** captured through a `Start-Process -RedirectStandardOutput`
  handle, so log lines are assertable despite AllocConsole.

**Coordinate magnitudes.** DXF-DATASET (`build\DXF-DATASET`) real plant drawings: mm units, extents
60k–2.44M CU. `main.py recenter()` anchors extents on each insert's *transformed block-bbox corners*
(not bare insert points — that left drawings 200k–310k CU off-origin when a block base point sat far
from its geometry). GPU 2D records + the view-center constant are float32 absolute CU: fine at
zoom-extents, but jitters when zoomed into detail ≥ ~100k CU from origin (ulp 0.0078 CU @ 100k,
0.125 @ 1M).

**Lesson from the "blank Page2D after zoom extents" hunt (2026-07-16):** it was never DXF or float32.
`Cad2DAutoGenerateDemoContent` (RenderPage2D.cpp) did `(n % 9) - 4` on unsigned, wrapping to ~4.29e9
before the float promotion and planting half the demo lines at 7.7e10 CU in *every* Page2D; zoom
extents fit that box and clamped zoom to 0.0001. Fixed by subtracting in double. Generalisable:
when "the import is broken", first dump the bbox of what's actually in the container — the demo
content shares it. Debug instrumentation left in place for this: ReportIngestStats sentinel,
zoom-extents bounds print with >1e8 outlier dump, per-10s 2D render heartbeat, OUTLIER AT
ENQUEUE/INGEST checkpoints.
